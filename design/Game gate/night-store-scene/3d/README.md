# 3D 블록아웃 → 이미지 생성

`view-center-v2.webp`(정면 사진)를 역산해 만든 매장 3D 모델이다.
AI가 공간을 지어내지 않도록, **구도·원근·물건 위치는 이 렌더가 정하고, AI는 재질과 분위기만 입힌다.**

## 파일

| 파일 | 내용 |
|---|---|
| `build_store.py` | 매장 전체를 만드는 Blender 스크립트. 치수는 맨 위 상수에서 고친다 |
| `night_store.blend` | 스크립트가 만든 장면. Blender에서 열어 직접 손봐도 된다 |
| `postprocess.py` | 렌더를 깊이 맵 / 선화 / 가이드로 변환 |
| `renders/pano_*.png` | **240° 원통형 파노라마** (2458×952) |
| `renders/photo_*.png` | 정면 사진과 같은 화각 (1672×941). 사진과 겹쳐 맞춰 봄 |

렌더마다 다섯 장이 나온다.

| 접미사 | 쓰는 곳 |
|---|---|
| `_color` | 색 가이드. 알록달록한 조각 = "상품이 빽빽한 진열" 자리 |
| `_guide` | 색 가이드 + 윤곽선. **이미지를 1장만 넣을 수 있는 AI(GPT 등)에 넣는 것** |
| `_depth` | 깊이 맵(가까울수록 흰색). ControlNet depth |
| `_lines` / `_lines_inv` | 윤곽선(흰 바탕 / 검은 바탕). ControlNet lineart·canny |

## 파노라마 크롭 (2458×952 기준, 16:9)

| 화면 | x 범위 | 보이는 것 |
|---|---|---|
| 좌 | 0 – 1692 | 바 테이블·스툴, 전자레인지, 유리 자동문, POS |
| 정면 | 383 – 2075 | 통로, 음료 냉장고, 호출벨 |
| 우 | 766 – 2458 | 과자 벽, 화장실 통로, CCTV 모니터, 보관함 |

> 원통형이라 16:9 한 화면이 가로 약 165°를 담는다. 그래서 좌우로 돌리는 폭은 ±38° 정도다.
> 41.6:9로 만들면 같은 세로 범위에서 약 430°가 필요해서 매장 뒤편까지 들어간다.
> v2–v5 확장에서 AI가 없는 공간을 지어낸 원인이 이것이다.

## 이미지 생성

### A. 이미지 넣는 AI (GPT 이미지, Gemini 등)

넣을 이미지: ① `renders/pano_guide.png` ② `../view-center-v2.webp`

```
첫 번째 이미지는 3D 블록아웃 렌더입니다. 두 번째 이미지는 원하는 실사 분위기입니다.

첫 번째 이미지의 구도, 원근, 곡선, 모든 물건의 위치와 크기를 완전히 그대로 유지한 채
두 번째 이미지처럼 사실적인 한국 편의점 사진으로 바꿔 주세요.

- 알록달록한 조각 무늬는 과자·라면·음료 상품이 빽빽하게 진열된 자리입니다
- 가로선이 휜 원통형 파노라마입니다. 휜 정도를 바꾸지 마세요
- 왼쪽: 통유리 창, 유리 자동문, 창가 나무 바 테이블과 스툴, 전자레인지와 온수기
- 가운데: 연두색 계산대, 호출벨, POS, 인수인계 메모, 진열대 통로, 안쪽 음료 냉장고
- 오른쪽: 과자 진열 벽, 벽에 뚫린 짧은 화장실 통로(흰 화장실 문, 회색 창고 문),
  직원 쪽으로 꺾인 계산대 위 CCTV 모니터(4분할 화면), 그 아래 뚜껑 있는 플라스틱 보관함 2개
- 새벽, 밖은 비 오는 어두운 밤. 천장 형광등의 차가운 흰빛, 광택 있는 타일 바닥
- 사람 없음. 글자와 로고는 읽히지 않게
- 렌더에 없는 벽, 통로, 진열대를 새로 만들지 마세요
```

### B. Stable Diffusion / Flux (ControlNet)

| 입력 | 파일 | 세기 |
|---|---|---|
| img2img 시작 이미지 | `pano_color.png` | denoise 0.6–0.75 |
| ControlNet depth | `pano_depth.png` | 0.8 |
| ControlNet lineart / canny | `pano_lines_inv.png` | 0.4–0.6 |
| 스타일 참고 (IP-Adapter 등) | `../view-center-v2.webp` | 0.5 |

## 다시 렌더하기

```bash
cd "design/Game gate/night-store-scene/3d"
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup -P build_store.py -- all
python3 postprocess.py
```

- `-- photo` 또는 `-- pano`로 하나만 렌더
- 빠른 확인: 앞에 `SAMPLES=16` (기본 48)
- 파노라마 가로 화각: 앞에 `PANO_DEG=200` (기본 240)
