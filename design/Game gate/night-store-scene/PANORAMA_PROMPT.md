# 파노라마 v6 확장 프롬프트

- 시작 이미지: `view-center-v2.webp` (1672×941)
- 목표 비율: 41.6:9 → 높이 941 기준 가로 약 **4350px**
- **한쪽씩 두 번에 나눠 확장**한다. 양쪽을 한 번에 늘리면 AI가 빈자리를 새 공간으로 채워서 매장이 넓어진다(v5).
  1. 오른쪽만 약 1340px 확장 → 약 3010×941
  2. 1의 결과에서 왼쪽만 약 1340px 확장 → 약 4350×941

## 매장을 좁게 유지하는 핵심

좁은 매장을 넓은 화각으로 보면 양옆에는 **새 공간이 아니라 보는 사람 옆으로 다가오는 벽**이 보여야 한다.

- 오른쪽 끝 = 과자 진열장이 붙은 오른쪽 벽이 가까이 다가옴
- 왼쪽 끝 = 자동문이 있는 정면 유리벽이 가까이 다가옴

v5는 이 벽들을 정면으로 돌려 세우고 그 사이를 바닥으로 채워 매장이 두 배로 넓어졌다.

## 1단계: 오른쪽

```
첨부한 이미지의 오른쪽만 확장해 주세요. 원본 부분은 절대 바꾸지 마세요.

[매장 크기]
- 좁은 동네 편의점. 원본 오른쪽의 과자 진열장은 매장 오른쪽 끝 벽에 붙어 있다
- 확장한 부분은 매장이 넓어지는 게 아니라, 이 오른쪽 벽이 보는 사람 옆으로 가까이 다가오는 모습
- 과자 진열장 너머에 새 진열대 줄, 새 통로, 넓은 빈 바닥을 만들지 않는다

[화장실 통로]
- 오른쪽 벽의 과자 진열장은 계산대 가까이에서 끝나고, 그 자리 벽에 폭 1m 정도의 통로 입구가 뚫려 있다
- 통로는 오른쪽으로 짧게 곧게 뻗고, 통로 끝 정면에 흰색 화장실 문(화장실 표지판)
- 통로 옆 벽에 회색 창고 문. 통로는 매장보다 조금 어둡다
- 통로 벽에도 같은 높이로 청록색 띠가 이어진다

[계산대]
- 앞쪽 연두색 계산대는 원본에서 그대로 이어지다가, 오른쪽 끝에서 보는 사람 쪽으로 부드럽게 휘어 다가온다
- 화면에서는 계산대 앞 모서리가 오른쪽 아래 구석을 향해 완만한 곡선으로 내려간다. 매장 안쪽(화면 위쪽)으로 휘거나 꺾이지 않는다
- 휘어 다가온 부분 위에 직원 쪽으로 돌려 놓은 CCTV 모니터(4분할 화면, 빈 매장)와 펜꽂이
- 그 아래 칸에 뚜껑 있는 반투명 플라스틱 보관함 2개
- 같은 높이, 두께, 광택으로 하나로 이어진 상판. 별도 책상, 단차, 흰색 받침 없음

[공통]
- 원통형 파노라마처럼 가로선은 가장자리로 갈수록 부드럽게 휘고, 세로선은 수직
- 같은 조명과 색감, 비 오는 새벽. 사람 없음, 글자와 로고는 읽히지 않게
```

## 2단계: 왼쪽 (1단계 결과를 넣고)

```
첨부한 이미지의 왼쪽만 확장해 주세요. 기존 부분은 절대 바꾸지 마세요.

[매장 크기]
- 원본 왼쪽의 유리 자동문은 매장 정면 유리벽에 있고, 이 유리벽이 화면의 왼쪽 벽이다
- 확장한 부분은 이 유리벽이 보는 사람 옆으로 가까이 다가오는 모습
- 보는 사람을 향한 새 벽이나 넓은 빈 바닥을 만들지 않는다

[창가]
- 자동문 왼쪽으로 통유리 창이 이어지고, 창을 따라 좁은 나무 상판 바 테이블과 동그란 스툴 3개
- 바 테이블도 유리벽을 따라 보는 사람 쪽으로 다가오는 방향으로 놓인다
- 왼쪽 끝 구석에 흰색 수납장, 그 위에 전자레인지, 온수기, 종이컵
- 창밖은 비 오는 어두운 밤, 가로등 주황빛

[계산대]
- 연두색 계산대는 POS와 인수인계 메모를 지나 왼쪽으로 조금 더 이어진 뒤 깔끔하게 끝난다
- 끝면은 같은 연두색 상판과 흰색 하부장 옆면. POS 아래에 흰색 받침이나 다른 높이의 판을 만들지 않는다
- 계산대 끝과 수납장 사이는 직원이 드나드는 좁은 빈 통로(폭 70cm 정도)
- 계산대 앞 모서리는 왼쪽 끝으로 갈수록 완만하게 휜다. 오른쪽과 대칭

[공통]
- 원통형 파노라마처럼 가로선은 가장자리로 갈수록 부드럽게 휘고, 세로선은 수직
- 같은 조명과 색감, 비 오는 새벽. 사람 없음, 글자와 로고는 읽히지 않게
```

## 안 될 때 바꿔 넣을 줄

| 문제 | 바꿔 넣을 줄 |
|---|---|
| 또 매장이 넓어짐 | "확장한 부분의 대부분은 가까이 다가온 벽(진열장 / 유리창)이 차지한다. 바닥은 조금만 보인다" |
| 화장실 통로가 벽 없이 열린 공간이 됨 | "통로는 양쪽이 벽으로 막힌 좁은 복도. 천장도 매장보다 낮고 조명은 하나" |
| 계산대가 위쪽으로 휨 | "계산대 오른쪽 끝은 화면 아래로 내려가며 화면 밖으로 나간다" |
| 너무 휘어 어안렌즈처럼 보임 | "곡선은 아주 완만하게, 양 끝에서 계산대 높이가 화면 높이의 5% 정도만 올라가게" |
| 보관함이 안 보임 | "휘어 다가온 계산대 아랫부분이 열린 선반이라 보관함 2개가 앞에서 보이게" |
| 사람이 생김 | "매장 안, 창밖, CCTV 화면 속 모두 사람 없음" |
