# 분위기: 청록빛 어둠 속의 밝은 섬

레퍼런스 보드: `refs-board.webp`

## 레퍼런스에서 읽은 것

| 레퍼런스 | 가져올 것 | 버릴 것 |
|---|---|---|
| 밤의 편의점 입구 (청록 안개, 빨간 간판) | 청록 색보정, 젖은 바닥, 안개 | |
| 夜勤事件 포스터 | 어둠 속 혼자 밝은 매장, 노란 간판 띠, 젖은 바닥 반사 | 컨셉이 매우 가까우니 '야간 편의점 이상현상' 이상으로 닮지 않게 |
| 청록 타일 리미널 공간 | 청록 단색 톤, 둥근 조명, 텅 빈 공간 | |
| 일본 편의점 실사 | 평범함의 기준 (상품 밀도, 조명) | 사람, 파란 브랜드 색 |
| 노란 백룸 | | 누런 색감 전체 |
| 8번 출구 | 밝고 단조로운 공간에서 '다른 점 찾기'. 플레이 방식의 기준 | |
| 꿀알바 포스터 | 청록·시안 매장 색보정, 냉장고 빛 | 어지럽혀진 매장 (엔딩이나 특수 장면용으로만) |

**공통점:** 7장 중 5장이 청록·시안 색보정, 4장이 젖은 바닥 반사다.
밝음 vs 어둠의 고민은 **"안은 밝고 밖은 어둡다, 전체를 청록으로 누른다"**로 정리된다.

## 방향

- **매장 안은 밝게.** 상태 레이어(물, 발자국, 떨어진 과자)가 보여야 하고, 8번 출구처럼 다른 점을 찾는 재미가 있어야 한다.
- **공포는 색과 바깥에서.** 청록으로 눌린 색, 끝없이 어두운 창밖, 젖은 반사.
- **따뜻한 색은 두 개만.** 연두색 계산대(위안), 빨강(수칙·경고·POP). 빨강이 나오면 긴장하도록.

| 1 | Q3 ~ Q4 | 청록이 짙어지고 안쪽 냉장고 위 형광등이 깜빡임 |
| 2 | Q5 ~ Q6 | 화장실 쪽·안쪽 조명이 꺼짐. 창밖 안개가 짙어짐 |
| 3 | Q7 ~ Q8 | 계산대 주변만 밝고 나머지는 깊은 청록. 바닥 반사가 가장 강함 |
| 새벽 | 05:48 이후 | 창밖이 회청색으로 밝아지는데 매장 안 색은 그대로 |

## 프롬프트 (정면)

넣을 이미지: `../3d/renders/photo_guide.png`, (선택) `refs-board.webp`

```
첫 번째 이미지는 3D 블록아웃 렌더입니다. 구도, 원근, 모든 물건의 위치와 크기를 그대로 유지한 채
비 오는 새벽, 어둠 속에 혼자 불 켜진 편의점 안을 찍은 사진으로 만들어 주세요.
두 번째 이미지는 색감 참고용이며, 사람, 글자, 포스터 구성은 따르지 마세요.

[톤]
- 전체 색감은 청록·시안빛. 밝은 곳은 차가운 시안 흰색, 어두운 곳은 깊은 청록 검정
- 매장 안은 형광등으로 밝고 균일하다. 매장 안을 어둡게 만들지 말 것
- 어두운 건 바깥뿐. 매장은 어둠 속에 떠 있는 밝은 섬

[매장 안]
- 광택 있는 타일 바닥이 젖은 듯 형광등을 길게 반사
- 형광등 빛에 아주 옅은 안개가 걸려 빛이 살짝 번짐
- 연두색 계산대는 청록 조명 아래에서도 연두색으로 또렷하게
- 상품은 빽빽하고 반듯하게 정렬. 색은 청록 톤에 눌려 살짝 탁하게
- 라벨, 글자, 로고는 읽히지 않게

[바깥]
- 유리창 밖은 짙은 청록 검정의 비 오는 밤. 젖은 바닥에 빛 반사
- 멀리 노란빛 가로등 하나. 유리에 빗방울과 매장 안 반사

[사진 느낌]
- 영화 스틸처럼 색보정됐지만 구도는 평범한 스냅. 정면을 그대로 바라보는 1점 투시
- 고운 필름 그레인, 약한 비네팅, 살짝 부드러운 초점

[금지]
- 사람, 형체, 피, 괴물, 낙서, 어지럽혀진 매장 없음
- 노란 백룸 같은 누런 색감 없음
- 렌더에 없는 벽, 통로, 진열대를 새로 만들지 말 것
```
