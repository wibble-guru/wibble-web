> **3D 블록아웃**: `3d/` 폴더. 매장을 3D로 만들어 렌더한 가이드로 이미지를 생성한다. 사용법은 `3d/README.md`.

플레이어는 계산대 뒤에 서 있고, **좌 / 우 버튼**으로 파노라마를 옆으로 밀어 시선을 돌린다.

```
 [◀ 좌: 창가 · 출입문]   [정면: 매장]   [우: 화장실 · CCTV ▶]
```

## 화면 자르는 위치 (16:9, panorama-v4 기준)

| 화면 | x 범위 | 보이는 것 |
|---|---|---|
| 좌 | 0 – 1248 | 창가 바 테이블과 스툴, 전자레인지·온수기, 유리 자동문, POS, 인수인계 메모 |
| 정면 | 376 – 1624 | 진열대 통로, 안쪽 음료 냉장고, 호출벨 |
| 우 | 752 – 2000 | 오른쪽 과자 진열장, 화장실 문·창고 문, CCTV 모니터, 계산대 아래 보관함 |

업스케일하면 x 값도 같은 배율로 곱한다(예: 2배 → 좌 0–2496).

## 0. 공통 규칙

| 항목 | 값 |
|---|---|
| 시점 | 계산대 뒤에 선 직원의 눈높이(약 160cm), 수평 시선 |
| 시간 | 새벽 2시~6시, 밖은 비 오는 밤 |
| 조명 | 천장 형광등, 밝고 균일한 차가운 흰빛. 밖은 어둡고 가로등만 주황빛 |
| 색 | 흰 천장, 광택 있는 회백색 타일 바닥, 벽 위쪽 청록색 띠, **연두색 계산대 상판** |
| 계산대 | 하나로 이어진 ㄷ자. 가운데는 화면과 나란한 일자, 양 끝은 45° 모서리를 거쳐 직원 쪽으로 꺾여 들어옴(날개 부분이 가운데보다 매장 쪽으로 조금 더 나와 있음). 왼쪽 날개에 인수인계 메모, 오른쪽 날개에 CCTV 모니터와 아래 보관함 |
| 사람 | **아무도 없음** |

> **가장 중요한 규칙**
> 젖은 옷을 입은 손님은 **눈으로 보는 화면에 절대 나오지 않는다.**
> CCTV 화면, 휴대폰 카메라, 사진 속에만 보인다.
> 그래서 파노라마에는 사람이 없어야 하고, 손님은 화면 속 화면(UI)으로만 넣는다.

## 1. 좌: 창가 · 출입문

| 물건 | 쓰이는 장면 |
|---|---|
| 유리 자동문, 문 앞 매트 | Q6-D, Q7, Q8-OUT, END-EXIT, TRUTH-03 |
| 자동문 센서(문 위, LED) | Q7, Q8-OUT "센서가 켜진다". **파노라마에 잘 안 보여서 작은 레이어로 따로 얹기** |
| 창가 바 테이블 · 스툴 | 스토리에는 안 나옴. 배경 |
| 인수인계 메모 | INTRO |
| POS | 계산 장면 |

**상태 변화**
| 상태 | 보이는 모습 | 조건 |
|---|---|---|
| 문 열림 | 자동문이 반쯤 열린 채 멈춤, 센서 LED 켜짐 | Q7 |
| 문 앞 젖은 바닥 | 매트 앞 타일이 젖어 반짝임 | `call=REQUEST` |
| 젖은 발자국 | 화장실 쪽에서 매트로 이어지는 젖은 신발 자국 | `bathroom=WAIT` 또는 `LOOK` + Q7 |
| 새벽 | 창밖이 약간 푸르게 밝아짐 | 05:48 이후 |

## 4. 파노라마 밖에서 따로 필요한 컷

| 컷 | 내용 | 장면 |
|---|---|---|
| 계산대 아래 | 몸을 숙여 본 시점: 전선, 박스, 바닥의 물방울 | Q2-A, Q4 |
| 냉장고 유리 클로즈업 | 거품 + **안쪽에서 찍힌** 손가락 자국 | Q3 |
| 화장실 문 앞 | 잠긴 문, 문 아래 물웅덩이 | Q5 |
| 휴대폰 잠금화면 | 계산대 아래에서 올려다본 구도로 찍힌 '나' | Q4 |
| CCTV 화면 | 천장 돔 카메라 시점. 계산대 앞에 **젖은 옷의 사람** | Q6, Q8-IN, TRUTH-03 |
| 메시지 / 통화 UI | 점장 메시지, 이전 근무자 메시지 | Q1-D, Q3-A, Q4-C, Q6, TRUTH-01 |
| 근무 수칙 문서 | 1~5번 수칙 + 볼펜 메모 / 0번 수칙 원본 | INTRO, END-WAIT, TRUTH-02 |
| 출입 센서 기록 | "퇴장 인원: 2명" | Q7-C, END-EXIT, TRUTH-03 |
| 매장 밖 | 비 오는 밤, 유리 너머로 본 빈 매장과 계산대 | Q8-OUT, END-EXIT |

> CCTV 화면은 파노라마와 **같은 매장**이어야 한다.
> 천장 돔 카메라 시점, 즉 "매장 안쪽 천장에서 계산대를 내려다본 모습"이다.
