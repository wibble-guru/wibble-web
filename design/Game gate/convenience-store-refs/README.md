## 같이 붙일 설명 (복사해서 사용)

```
첨부한 이미지는 한국 편의점 레퍼런스입니다. 번호는 이미지 왼쪽 위 라벨입니다.

[공간 구조]
- 정면은 통유리 + 유리문 입구(01, 03, 04). 입구 옆에 계산대가 있다(01, 02, 07).
- 매장 가운데는 평행한 회색 금속 진열대 통로(09, 10, 11), 안쪽 벽은 유리문 음료 냉장고와 오픈형 유제품 냉장대(08, 02).
- 계산대 뒤 벽에는 조명이 들어간 담배 진열장과 광고판, 계산대 위에는 POS·카드 단말기·껌/사탕 소형 진열(05, 06).

[재질과 색]
- 천장: 흰색, 길쭉한 LED 라인 조명이 여러 줄로 배치.
- 바닥: 밝은 회백색 타일, 약간 반사.
- 벽 위쪽: 연두색 띠(게임 화면) 또는 청록색 띠(실사 03, 13). 
- 계산대 상판: 연두색.
- 선반: 상품이 빽빽하게 꽉 찬 상태, 선반 앞에 가격표 띠, 진열대 끝에 행사 POP.

[조명과 분위기]
- 기본: 밝고 균일한 차가운 흰색 형광등 조명(04–13).
- 14번만 예외적으로 어두운 밤 분위기.

[무시할 것]
- 사람과 군인 캐릭터, 게임 자막과 UI, 유튜브 안내 배너, 오른쪽 아래 워터마크, 날짜 도장(02, 14), 모자이크된 얼굴(03).
- 실제 브랜드 로고(GS25, Oomphf 등)는 그대로 쓰지 말고 비슷한 느낌의 가상 브랜드로 바꿀 것.
```
