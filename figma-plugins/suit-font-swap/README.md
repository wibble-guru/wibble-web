# SUIT Font Swap (Figma 플러그인)

**로고(Gumi Romance)와 포스터 제목 폰트를 제외한 모든 텍스트 폰트를 SUIT Variable로** 바꾸는 개발용 Figma 플러그인입니다.

## 설치 (한 번만)

1. Figma 데스크톱 앱에서 디자인 파일을 엽니다.
2. 메뉴 **Plugins → Development → Import plugin from manifest…**
3. 이 폴더의 `manifest.json`을 선택합니다.

이후 **Plugins → Development → SUIT Font Swap**으로 실행합니다.
SUIT Variable(과 Gumi Romance)은 이 컴퓨터에 설치되어 있어야 합니다.

## 사용법

1. **범위**를 고릅니다: 선택 영역 / 현재 페이지 / 모든 페이지.
2. 표에서 바뀔 폰트(`변경`), 그대로 둘 폰트(`유지`), 이미 SUIT인 폰트를 확인합니다. 열자마자 자동으로 검사합니다.
3. **SUIT로 바꾸기**를 누릅니다. 결과가 마음에 들지 않으면 `Cmd+Z`로 되돌립니다.

## 규칙

| 상황 | 처리 |
|---|---|
| 패밀리 이름에 `Gumi Romance` 또는 포스터 제목 폰트(EF_watermelonSalad, Song Myung, Orbit, Bagel Fat One, Gowun Dodum, Gowun Batang, Black Han Sans, Black And White Picture, Jua)가 들어감 | 그대로 둠 (대소문자·공백·밑줄 무시) |
| 그 밖의 모든 폰트 | `SUIT Variable`로 변경 |
| 굵기 | 원래 굵기(weight)에 가장 가까운 SUIT 스타일. 동률이면 더 굵은 쪽 |
| 이탤릭 | SUIT에 이탤릭이 없어 정체로 바뀜 (개수를 알려줌) |
| 한 텍스트 안에 폰트가 섞여 있음 | 구간별로 처리 (유지 폰트 구간만 그대로) |
| 메인 컴포넌트 / 인스턴스 | 메인을 먼저 바꿔서 인스턴스는 오버라이드 없이 따라옴 |
| 로컬 텍스트 스타일 | 옵션 켜짐(기본): 스타일 자체를 바꿔서 링크 유지. **파일 전체**에 적용됨 |
| 라이브러리 텍스트 스타일이 걸린 텍스트 | 기본은 건너뜀. 옵션을 켜면 바꾸지만 스타일 연결이 끊어짐 |
| 폰트 패밀리 변수가 연결된 텍스트 | 건너뜀 (변수 값을 바꾸세요) |
| 원래 폰트가 설치되지 않은(missing) 텍스트 | 그대로 SUIT로 바꿀 수 있음 |

## 알아둘 점

- 검사 단계의 "바꿀 곳" 숫자는 **예상치**입니다. 메인 컴포넌트가 범위 안에 있으면 그 인스턴스 텍스트는 따로 바꿀 필요가 없어 실제 변경 수가 조금 적게 나옵니다.
- 인스턴스만 범위에 있고 메인 컴포넌트가 다른 페이지에 있으면, 인스턴스 쪽에 폰트 오버라이드가 생깁니다. 깔끔하게 하려면 **모든 페이지**로 실행하세요.
- 라이브러리(다른 파일)의 컴포넌트는 이 파일에서 메인을 바꿀 수 없어 인스턴스에 오버라이드로 들어갑니다.
- 대상/유지 폰트 이름은 `code.js` 맨 위 `TARGET_KEYS`, `KEEP_KEYS`에서 바꿀 수 있습니다.

## 파일

- `manifest.json` — 플러그인 설정 (네트워크 접근 없음, 페이지 단위 로딩)
- `code.js` — 변환 로직. `<core>` 블록은 전역 상태 없이 작성되어 그대로 테스트할 수 있습니다.
- `ui.html` — 플러그인 창 (Figma 라이트/다크 테마 색 사용)
